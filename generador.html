Generador de preguntas para el cuestionario

Completá el formulario y copiá el bloque generado dentro del arreglo QUESTIONS en data.js (antes del corchete final ]).


  

  

    Instrucciones para agregarla:

    1. Abrí data.js en GitHub (lápiz de editar).

    2. Buscá el arreglo const QUESTIONS = [ ... ].

    3. Pegá el bloque generado justo antes del ] final, agregando una coma después del último elemento existente.

    4. Guardá los cambios (commit).
