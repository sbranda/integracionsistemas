Generador de preguntas

Completá el formulario y generá el bloque de texto listo para pegar en data.js, sin escribir código a mano. Esta página no aparece en la app de los alumnos. 


    
  


  

    ¿Cómo lo agrego a la app?
    
    
      
  1. Generá el bloque de arriba y tocá "Copiar al portapapeles".
    2. 
      
  2. Abrí el archivo data.js del proyecto (en GitHub o en tu computadora).
    3. 
      
  3. Buscá const QUESTIONS = [ y bajá hasta encontrar el ]; que cierra ese arreglo específico (ojo: más abajo en el archivo hay más contenido, como MISCONCEPTIONS — asegurate de pegar dentro de QUESTIONS, no después).
    4. 
      
  4. Pegá el bloque copiado justo antes de ese ]; (después de la coma del último bloque existente).
    5. 
      
  5. Guardá el archivo y subilo a GitHub (Add file → Upload files → Commit changes).
